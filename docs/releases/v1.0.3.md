# v1.0.3 — 未连接也能看关于/更新，修断开闪退与热点加入

## 新增：onepage-hub 固件 OTA

设备固件是 `onepage-hub-*` 时，「更多 → 设备」多出「固件升级」：

- 从 Gitee 镜像 `Yann_Fang/onepage-hub` 取最新 Release，失败回退 GitHub `YannFang2002/onepage-hub`
- 只认 Release 里名为 **`firmware.bin`** 的附件（onepage-hub 自己的 OTA 也只接受它；0x0 整包会被设备校验拒绝）
- 下载 → `POST /api/ota`（multipart 字段 `firmware`）→ 轮询 `GET /api/ota/status`
- 界面分三段显示进度：下载固件 / 上传到设备 / 设备校验与写入；完成后设备自行重启

固件不是 `onepage-hub-*` 时页面明确说明「此固件不支持 App 内升级」，不影响其它功能。

## 修复

**断开设备后 App 直接退出。** 「设备 → 断开连接」会先把 `api` 置空再切状态，而根部的
`AnimatedContent` 在播放退出动画期间仍会重组旧的 `MainShell`，于是 `api!!` 抛 NPE，进程被杀。
现在退出动画使用它自己那一帧的 `DeviceApi` 快照，断开后稳定落回扫描/连接页，不再退出 App。

**没连设备时进不去「关于 / 检查更新」。** 连接页底部新增「关于与更新 · v1.0.3」，未连设备也能
看版本、检查更新、下载安装包；「关于」页里也新增了「软件更新」入口，两页可互相返回。

**扫码加入未加密热点失败，只能手动去系统设置连。** 自动加入现在会区分原因并给出对应出口：

| 失败原因 | 界面动作 |
|---|---|
| 缺「附近的设备」权限 | 卡片里直通「打开应用权限设置」 |
| 手机 Wi-Fi 关闭 | 提示开后重试，并给 Wi-Fi 列表入口 |
| 系统弹窗被取消 / 被「自动切换网络」打断 | 提示可重试，并给 Wi-Fi 列表入口 |
| 等待超时 | 同上 |
| 已连上热点但访问不到设备 | 每 2 秒探活，最长 90 秒 |

无论哪条路径，**用户手动连上热点后 App 会自动继续连接设备**，不用重新扫码。
请求本身也修正为不要求 `NET_CAPABILITY_INTERNET`（阅读器的热点没有外网，部分 ROM 会因此
永远判定网络「不可用」），并显式声明非隐藏 SSID。

## 变更

- `versionCode` 3 → 4，`versionName` 1.0.2 → 1.0.3
- 连接页新增「关于与更新」入口；「关于」页新增「软件更新」行
- 新增 `WifiJoinFailure` / `WifiJoinResult` / `wifiJoinMessage`，加入失败不再只有一句笼统提示
- 新增 `core/firmware/`（固件源、Release 解析、下载、`/api/ota` 推送）与「固件升级」页
- 单元测试 48 → 73（新增 `WifiJoinTest` 6、`FirmwareParserTest` 10、`FirmwareApiTest` 6，`DeviceApiTest` +3）

## 安装

下载 `OnePage-1.0.3.apk` 直接安装，Android 8.0+（minSdk 26）。

可覆盖升级 1.0.0 / 1.0.1 / 1.0.2（同签名），无需卸载。
