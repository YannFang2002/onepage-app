# v1.0.4 — 更新直接在 App 里下完并安装

## 新增

**应用内下载 + 安装。** 「软件更新」不再必须跳浏览器：

1. 点「下载并安装」→ App 自己从 Gitee 镜像 / GitHub 拉取 APK，显示进度；
2. 下载完成按 Release 的 `digest` 校验 SHA-256（Gitee 未提供时只校验长度），不符即删文件报错；
3. 校验通过后通过 `FileProvider` 交给系统安装器，停留在 App 内完成覆盖安装。

首次安装会弹「未知来源」限制，App 会直接把用户送到 OnePage 的「安装未知应用」开关，授权后回到更新页点
「打开系统安装器」即可。启动时的新版本弹窗也改成「下载并安装」，直接在本机完成，不再打开浏览器。
进度、失败原因、重试都在更新页里；浏览器入口保留为备用。

## 变更

- `versionCode` 4 → 5，`versionName` 1.0.3 → 1.0.4
- 「固件更新」入口同时放进**设备信息**页（只在该固件为 `onepage-hub-*` 时出现），与「更多 → 设备」里的入口等价
- 新增 `REQUEST_INSTALL_PACKAGES` 权限（仅用于把用户带到系统安装器，不静默安装）
- `ReleaseAsset` 增加 `digest` → `sha256` 归一化；`UpdateApi.download()` 落盘 + 校验 + 进度
- `UpdateViewModel` 增加下载状态机（下载中 / 已下载 / 失败），切换版本时自动作废旧包
- 「关于与更新」在未连接设备时同样可下载安装
- 工程合并：原先并列的 `onepage-hub-app` 副本已合并进本仓库；签名 key（`onepage-release.jks` +
  `keystore.properties`）放在仓库根目录并保持 git-ignored
- 单元测试 73 → 77（`ReleaseParserTest` 12、`UpdateApiTest` 8）

## 安装

下载 `OnePage-1.0.4.apk` 直接安装，或直接在 1.0.3 的「软件更新」里点「下载并安装」。

可覆盖升级 1.0.0 – 1.0.3（同签名），无需卸载。
