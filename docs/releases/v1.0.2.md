# v1.0.2 — 增加检查更新

OnePage 手机伴侣 App 1.0.2。这一版只做一件事：让 App 自己能发现新版本，并把下载入口送到手边。

## 新增

**进应用即检查更新**：每次启动静默向 Gitee 镜像 / GitHub Releases 查询最新正式版本，
发现比当前更新的版本时弹一次确认框，「前往下载」交给系统浏览器；「稍后」关闭后本次启动不再打扰。

**更多 → 软件更新**：手动重查、看当前版本、发布渠道、上次检查时间、发布日期、安装包大小与完整更新说明；
已是最新时明确告知，检查失败时给出两个源的具体原因（限流 / 无法访问 / 超时）。

**镜像优先**：先查 Gitee（`gitee.com/Yann_Fang/onepage-app`），不可用再回退 GitHub
（`github.com/YannFang2002/onepage-app`）。两个源都不带 token，也不做静默安装——App 不申请
「安装未知应用」权限，下载和安装都由系统完成。

## 变更

- `versionCode` 2 → 3，`versionName` 1.0.1 → 1.0.2
- 新增 `core/update/`：更新源（Gitee / GitHub）、Release 解析、版本比较（`v1.0.2` / `release-1.0.3` / `1.0.4-beta` 均可解析）
- 新增 `UpdateViewModel`：启动即查、磁盘无关的状态机、两源合并报错
- 新增「软件更新」页与「更多 → 应用」分组
- `formatSize` 从文件页移到通用组件，供文件列表与更新页共用
- 单元测试 32 → 48 个（新增 `ReleaseParserTest` 11 例、`UpdateApiTest` 5 例）

## 安装

下载 `OnePage-1.0.2.apk` 直接安装，Android 8.0+（minSdk 26）。

可覆盖升级 1.0.0 / 1.0.1（同签名），无需卸载。
